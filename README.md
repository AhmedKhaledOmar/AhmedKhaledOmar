## 👋 About me

I'm a Senior Software Engineer at **Limitless Care**, leading the **Insurance System**: a multi-tenant platform being built from scratch toward production on **.NET 8 and Angular**, with RBAC, audit trails, medical coding modules and background jobs on Hangfire. I write code every day and run the team around it.

Before that I was at **BitBang** until May 2026, and overall I've been building enterprise software for **5+ years**. Along the way I mentor **8 to 10 junior engineers**.

- 🏥 Home turf: healthcare and insurance systems
- 🧩 Complex business workflows, multi-tenancy and background processing
- 👨‍🏫 Technical planning, code review and mentoring
- 🌍 Based in Egypt
